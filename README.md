# 🛒 Customer Shopping Behavior Analysis

## 📌 Project Overview

Customer Shopping Behavior Analysis is a data analytics project that examines customer purchasing patterns using transactional data. The project focuses on identifying customer behavior, product preferences, spending trends, and subscription patterns to support data-driven business decisions.

The project combines **Python**, **PostgreSQL**, **SQL**, and **Power BI** to perform data cleaning, business analysis, and interactive dashboard visualization.

---

## 🎯 Objectives

* Analyze customer shopping behavior and purchasing trends.
* Clean and preprocess raw transactional data.
* Perform business-focused SQL analysis.
* Build an interactive Power BI dashboard.
* Generate actionable business recommendations.

---

## 📊 Dataset Information

* **Total Records:** 3,900
* **Total Features:** 18

### Dataset Includes

* Customer Demographics

  * Age
  * Gender
  * Location
  * Subscription Status

* Purchase Details

  * Product Category
  * Item Purchased
  * Purchase Amount
  * Season
  * Size
  * Color

* Shopping Behavior

  * Discount Applied
  * Previous Purchases
  * Purchase Frequency
  * Review Rating
  * Shipping Type

---

## 🧹 Data Preprocessing (Python)

The dataset was cleaned and transformed using Python.

### Steps Performed

* Imported dataset using Pandas
* Explored data using `info()` and `describe()`
* Handled missing values in the Review Rating column
* Renamed columns using snake_case naming convention
* Created new features:

  * Age Group
  * Purchase Frequency (Days)
* Removed redundant columns
* Loaded cleaned data into PostgreSQL
